
## Explainable Stroke Risk Prediction — Healthcare ML

- Predicting stroke risk using interpretable machine learning on imbalanced healthcare data.

## Key highlights:

- Logistic Regression achieved ROC-AUC 0.852, outperforming Random Forest and XGBoost
- SHAP explainability confirms age, glucose, hypertension as top clinical predictors
- Imbalance-aware evaluation using Precision-Recall AUC and threshold optimization
- Validated clinical plausibility of model outputs

## Tools: Python, Scikit-learn, XGBoost, SHAP, Pandas, Matplotlib

## Dataset: Healthcare stroke prediction — public dataset
